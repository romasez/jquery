# Assignment 6 - jQuery Portfolio

**Student:** Sailau Ramazan 
**Group:** SE  - 2539

## About this project

I created a simple personal portfolio website for Assignment 6. I used HTML to create the page, CSS to style it, and jQuery to make the buttons interactive.

## Tasks

- **Task 0:** Connected jQuery using a CDN and checked it in the console.
- **Task 1:** Used tag, class, and ID selectors. Changed text and CSS. Added light and dark themes.
- **Task 2:** Added Hide, Show, and Toggle buttons to the About Me section.
- **Task 3:** Added two gallery pictures with fade effects.
- **Task 4:** Created three sections that open and close using slide effects.
- **Task 5:** Added a list of skills and buttons to add, prepend, and remove skills.
- **Task 6:** Changed the social link using the `attr()` method.
- **Task 7:** Displayed typed name and email in real time.
- **Task 8:** Animated skill bars using the `animate()` method.
